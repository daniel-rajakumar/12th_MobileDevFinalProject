# 12th_MobileDevFinalProject

>  About the app in a single sentence.
*   A gradview app made for SBHS students to view their grades in ease and securely. 

<hr>

> Why this app compare to genesis?
* Auto login
* Offline view
* Better UI and UX
* Faster than opening browser everytime.
* Biometric login for extra security. 
* Check assigments with intuitive calendar view. 

<hr>



> FEW new techologies: 
- Web scraping (Puppetter in node.js)
- HTTP Web server (frontend: retrofit, backend express.js)
- Fragments
- Backend in different programming language (node.js)
- A local database (.txt file haha) on the server that stores user's username, picture, and password (encrypted)
